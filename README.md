<h1>Мраморный карьер Рускеала </h1>
<p align="justify">
 Рускеальские каменоломни — это памятник природы и горного дела.
Они находится в Сортавальском районе, в 24 километрах к северу
от города Сортавала, рядом с поселком Рускеала. Мрамор тут добывали
ещё с конца XVII века. Рускеальский мрамор использовался при
украшении очень многих архитектурных шедевров Петербурга,
Царского Села, Гатчины. Только с 1769 по 1830 год здесь
наломали 200 000 тонн мрамора.
</p>
<p align="justify">
 Самым интересным считается Мраморный каньон. Это заполненный
естественными водами самый старый карьер открытой добычи камня.
Отсюда были получены блоки для облицовки многих архитектурных
творений Санкт–Петербурга:
</p>
<ul>
 <li> <a href="https://ru.wikipedia.org/wiki/Исаакиевский_собор"> Исаакиевского собора </li> </a>
 <li> <a href="https://ru.wikipedia.org/wiki/Казанский_собор_(Санкт-Петербург)"> Казанского собора </li> </a>
 <li> <a href="https://ru.wikipedia.org/wiki/Эрмитаж"> Эрмитажа </li> </a>
 <li> <a href="https://ru.wikipedia.org/wiki/Мраморный_дворец_(Санкт-Петербург)"> Мраморного дворца </li> </a>
 <li> <a href="https://ru.wikipedia.org/wiki/Михайловский_замок"> Михайловского замка </li> </a>
 <li> станций метро «Приморская»
и «Ладожская». </li>
</ul>
<p>
Добраться до карьера Рускеала от Петрозаводска не так просто:
<ol>
 <li> вначале нужно ехать по трассе <a href="https://ru.wikipedia.org/wiki/Европейский_маршрут_E105"> E105 </a> (М18) до Пряжи </li>
 <li> свернуть направо и двигаться по трассе Р21 в сторону <a href="https://ru.wikipedia.org/wiki/Сортавала">
Сортавала </a> </li>
 <li> не доезжая до Сортавала, свернуть на <a href="https://ru.wikipedia.org/wiki/Вяртсиля"> Вяртсиля </a> </li>
 <li> проехать поселок <a href="https://ru.wikipedia.org/wiki/Рускеала_(горный_парк)"> Рускеала </a> </li>
 <li> затем будет мост через речку Тохмайоки, сразу за которым будет указатель
налево к Мраморному каньону </li>
</ol>
